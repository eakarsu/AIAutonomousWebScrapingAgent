# Governed crawl operations

Jobs require exact HTTPS host allowlists, robots evidence, bounded rates/pages/bytes, and an extraction contract. Workers must resolve DNS and reject every private/non-public address immediately before every connection, including redirects. Records preserve canonical URL, observation time, content digest, deduplication key, and an untrusted-content marker.

Bootstrap/migrations are explicit and start is non-mutating. Unauthenticated browser/CUA and generated gap endpoints are quarantined. Real browser workers, queues, object storage, approved proxy policy, downstream contracts, robots retrieval, DNS pinning, retries, and site-specific accuracy evaluation remain deployment work.
